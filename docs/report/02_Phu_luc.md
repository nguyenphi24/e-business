# HƯỚNG DẪN ĐỌC PHỤ LỤC

Tài liệu này đi kèm đề cương báo cáo và chứa đặc tả chi tiết mà thân báo cáo chỉ tóm tắt.

| Phụ lục | Nội dung | Liên hệ với thân báo cáo |
|---|---|---|
| A – URD | Vai trò, phạm vi P0/P1/P2, quy trình Source-to-Pay, user stories, quy tắc nghiệp vụ, tiêu chí nghiệm thu | Mục 1, 3 |
| B – SRS | Ma trận quyền, yêu cầu chức năng, state machine, công thức chấm điểm, định nghĩa KPI, dữ liệu, API, yêu cầu phi chức năng | Mục 3, 6, 8 |
| C – HLD | Kiến trúc container, module, mô hình dữ liệu, luồng sự kiện, thanh toán sandbox, bảo mật, triển khai, truy vết kinh doanh → kiến trúc | Mục 6 |
| D – Kiểm thử và demo | Test case, kết quả chạy thật, kịch bản demo, bảng trạng thái Đề xuất / Đã triển khai / Đã kiểm thử | Mục 6.11, 7.2, 9 |

Tên vai trò, trạng thái và đường dẫn API giữ nguyên tiếng Anh như trong mã nguồn để người đọc đối chiếu được với hệ thống chạy thật.
